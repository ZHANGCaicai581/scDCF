# Examples

These scripts are lightweight public examples for package users.

## Files

- `parallel_example.py`: serial versus parallel Monte Carlo usage
- `generate_test_data.py`: create a small synthetic AnnData object and gene list
- `cell_id_workflow.py`: inspect a final summary with merged metadata
- `organize_output_examples.py`: show the default output layout from a completed run

The examples are intentionally small and focused on the current public API.
